# CRM System

This project is a comprehensive Customer Relationship Management (CRM) solution built with a .NET backend and an Angular frontend. It is designed to manage contacts, track sales orders, and provide real-time updates on business activities.

## How to Run

The easiest and recommended way to run this application is using **Docker Compose**. This ensures that the backend and frontend services are configured correctly and run in a consistent environment.

### Using Docker (Recommended)

1. Ensure [Docker](https://www.docker.com/) and [Docker Compose](https://docs.docker.com/compose/) are installed on your machine.
2. From the project root, start the entire stack:
   ```bash
   docker compose up --build
   ```
3. The application will be accessible via your browser.

*Note: Docker Compose handles all service orchestration, dependencies, and networking automatically.*
